# NEXUS — Tic-Tac-Toe

A modern, interactive Tic-Tac-Toe web application featuring a futuristic
gaming interface, two-player gameplay, and an AI opponent.

## Features

- Responsive neon-themed user interface
- Two-player mode
- Player versus computer mode
- Three AI difficulty levels
- Minimax algorithm for optimal AI gameplay
- Automatic win and draw detection
- Animated winning cells
- Live scoreboard
- Round reset and new-game controls
- Procedural sound effects with mute control
- Keyboard-accessible buttons and responsive layouts

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Web Audio API

## Run Locally

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No package installation is required.

## How to Play

1. Select Two Players or VS Computer.
2. Choose an AI difficulty when playing against the computer.
3. Place three matching symbols in a row, column, or diagonal to win.
4. Use Reset Round to replay without clearing scores.
5. Use New Game to reset the scoreboard.

## AI Implementation

The Impossible difficulty uses the minimax algorithm to evaluate
possible moves and select an optimal strategy.
